About

Understanding the problem comes before writing the code.

It started with curiosity, not a career plan — wanting to know why things worked the way they did. That curiosity turned into late nights with C++ and Java, then into databases and system design, then into full applications. Somewhere between my first out-of-bounds error and my first ER diagram, I realized I wasn't just picking up syntax — I was learning how to think through problems properly.

That curiosity now has a direction: full-stack .NET development, built through the DEPI Full-Stack .NET track — ASP.NET Core, React, SQL Server, and everything in between. But what actually drives the work isn't the stack, it's the question behind every project: what problem am I really solving, and who is it for.

"I don't just build features — I look for the problem behind them, and turn it into a solution that creates real value for the people using it."

PROJECT · 01

Smart Student Performance Platform

ASP.NET Core · C# · SQL Server · Entity Framework · React
Problem

Teachers can see grades and attendance, but raw records don't explain why a student's performance is changing.

Solution

A platform that tracks performance, attendance, and trends — and surfaces early warning signs instead of just logging numbers.

My role

Full-stack development and database design, end to end.

Result

Teachers can spot declining students early and act on it, while keeping tabs on strong performers too.

PROJECT · 02

Hotel Management System

Microsoft Access · SQL · Database Design
Problem

Guest records, rooms, and reservations needed a structured system instead of scattered manual tracking.

Solution

A relational database that organizes guests, rooms, and bookings with clean, queryable relationships.

My role

Database design and query development.

Result

Reliable data retrieval and simpler day-to-day management of reservations.
